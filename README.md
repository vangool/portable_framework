# Project Repository

This repository contains the project within a subdirectory.

## Clone the repository

```bash
git clone git@github.com:vangool/portable_framework.git
cd portable_framework
git submodule update --init --recursive
```

## Navigate to the project

The project is located in the `modular_sensor_actuator` subdirectory.

```bash
cd modular_sensor_actuator
```

From there, refer to the project's documentation:

* [`README.md`](./modular_sensor_actuator/README.md)

The project README contains the setup instructions, development workflow, and additional documentation.
